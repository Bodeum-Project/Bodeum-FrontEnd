# 보듬보듬 랜딩페이지

`preview.html`을 브라우저에서 열면 랜딩페이지와 네 가지 기능 안내를 볼 수 있습니다. 파일 미리보기에서 출시 알림 폼을 제출하면 안내 메시지가 표시되며 이메일은 저장되지 않습니다.

## 출시 알림 접수 확인

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

서버가 표시한 주소에서 신청하면 `POST /api/launch-signups`가 이메일, 동의 기록, 신청자가 선택한 보호자 역할과 나이대를 `.launch-signups/`에 저장합니다. 역할과 나이대는 선택 사항이며 빈 항목과 응답 거절은 기록하지 않습니다. 동일 주소로 다시 신청해도 기존 기록을 유지합니다. 저장 위치는 `BODEUM_SIGNUP_DIR`로 바꿀 수 있습니다.

빌드 결과도 `npm run build` 후 `npm run preview -- --host 127.0.0.1`로 열면 같은 접수 기능을 사용할 수 있습니다. `npm run preview:export`는 브라우저에서 바로 열 수 있는 HTML을 다시 생성합니다.

## 베타 배포

공개 환경에는 정적 빌드와 함께 출시 알림 접수 API 및 비공개 영속 저장소를 연결해야 합니다. Vite의 접수 API는 개발 및 검토 환경에서 확인하기 위한 구현입니다. 출시 시 운영자가 동의가 기록된 신청 주소를 메일 발송 서비스의 수신자 목록으로 가져와 알림을 보낼 수 있습니다. 발송 서비스 연동과 발송 후 신청 기록 삭제는 운영 환경에서 처리해야 합니다.
